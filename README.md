# Gui's Photos

Static photography portfolio and GitHub Pages site for Gui Roque.

This repository contains the source for the public portfolio at `https://eoqrupics.com`. It is built with plain HTML, CSS, and JavaScript. The gallery is generated from the image files in the repository, so new work can be added without editing gallery markup by hand.

## Adding Photos

1. Add image files to `assets/images/`.
2. Commit and push to `main`.
3. GitHub Pages runs `npm run generate:gallery` during deployment.
4. New images appear at the top of the gallery automatically.

For a local preview after adding images:

```bash
npm run generate:gallery
```

Do not edit `data/gallery.js` or `sitemap.xml` manually. They are generated by `scripts/build-gallery-data.js`.

The generator sorts images by their latest Git commit timestamp, so newly committed photos appear at the top of the grid. It also reads each image's dimensions, writes them into the generated gallery data, and adds image detail URLs to the sitemap.

## Image Metadata

Optional metadata lives in `data/gallery-meta.json`.

Supported fields:

- `alt` - accessible image description.
- `cameraSettings` - camera and lens information.
- `imageResolution` - shot settings and resolution.

The work detail page only shows camera information when `cameraSettings` or `imageResolution` exists for that image.

If `assets/images/about-portrait.jpg` is added later, the generator skips it so it can be used by the about page instead of the gallery.

## Static Site Files

- `sitemap.xml` lists the public pages and generated image detail URLs for search engines.
- `robots.txt` points crawlers to the sitemap.
- `404.html` is the GitHub Pages fallback for missing routes.
- `site.webmanifest` and `assets/icons/favicon.svg` provide the browser icon and basic app metadata.

## Local Use

Open `index.html` in a browser.

The site does not require a local dev server because it does not use runtime `fetch()` calls.

## Deployment

Deployment is handled by `.github/workflows/pages.yml`.

On every push to `main`, the workflow:

1. Checks out the repository.
2. Runs `npm run generate:gallery` to refresh the gallery data and sitemap.
3. Copies the static site files into a Pages artifact.
4. Uploads and deploys the artifact to GitHub Pages.
